Contenido Principal

El Holy Grail Layout es un patrón clásico de diseño web que ha evolucionado con las modernas tecnologías CSS. Consiste en:

Header (cabecera)
Navigation (navegación)
Main Content (contenido principal)
Sidebar (barra lateral)
Footer (pie de página)

Implementación con CSS Grid

Con CSS Grid, este layout es extremadamente fácil de implementar usando la propiedad grid-template-areas:

.holy-grail {
    display: grid;
    grid-template-areas: 
        "header header header"
        "nav main sidebar"
        "footer footer footer";
}

Responsive Design

La magia de CSS Grid permite que este layout se adapte perfectamente a cualquier dispositivo con simples cambios en las áreas del grid.

Desktop
Tablet
Mobile
