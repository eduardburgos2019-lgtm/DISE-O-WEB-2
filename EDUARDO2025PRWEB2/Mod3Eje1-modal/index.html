Ejercicio: Modal Centrado

Haz clic en el botón para abrir el modal centrado con overlay semitransparente y efectos visuales modernos.

Características del Modal:

  • Centrado con position: fixed y flexbox
  • Overlay semitransparente con blur effect
  • Cierre con botón X animado (360°)
  • Cierre al hacer clic fuera del modal
  • Transiciones suaves y animaciones CSS
  • Diseño completamente responsive
  • Gradientes modernos y sombras depth
  • Efectos hover en todos los elementos
  • Iconos SVG y Font Awesome
  • Soporte para modo oscuro

¡Bienvenido al Modal!

Este es un modal centrado usando position: fixed con display: flex para centrado perfecto.

El overlay tiene efecto blur y el modal incluye animaciones de entrada y salida. También puedes cerrarlo presionando la tecla ESC.
