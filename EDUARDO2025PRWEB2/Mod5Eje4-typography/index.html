Introducción a la Fluidez

Este párrafo demuestra el cuerpo de texto fluido. Si redimensionas la ventana del navegador, notarás que el tamaño de la fuente no salta de un tamaño a otro (como pasaría con media queries tradicionales), sino que escala matemáticamente gracias a la función clamp().

Texto para notas al pie o elementos secundarios.
clamp(0.875rem, 0.95rem + 0.3vw, 1rem)

La función clamp() toma tres valores: un tamaño mínimo, un tamaño preferido (que usa viewport units), y un tamaño máximo. Esto crea un rango fluido entre los puntos de ruptura.

Por ejemplo, clamp(1rem, 1.05rem + 0.4vw, 1.125rem) significa:

  • Mínimo: 1rem (16px)
  • Preferido: 1.05rem + 0.4% del ancho de la ventana
  • Máximo: 1.125rem (18px)

¿Cómo funciona?

Este diseño utiliza variables CSS (--text-*) para definir un sistema tipográfico completo que se escala fluidamente entre los anchos de pantalla mínimo y máximo. Los tamaños se calculan dinámicamente usando la función clamp().

Consejo: Intenta cambiar el tamaño de la ventana del navegador lentamente y observa cómo todos los elementos de texto se escalan suavemente sin saltos abruptos.
