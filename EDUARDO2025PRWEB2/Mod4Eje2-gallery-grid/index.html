Cómo Funciona Este Grid

CSS Grid Con Auto-fit

.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 1.5rem;
}

/* ⭐ auto-fit: Crea automáticamente columnas que caben en el contenedor
⭐ minmax(300px, 1fr): Mínimo 300px, máximo 1 fracción del espacio
⭐ Resultado: Grid completamente responsive SIN media queries */

Auto-fit

Calcula automáticamente cuántas columnas caben en el ancho disponible

Minmax()

Define límites: mínimo 300px, máximo 1 fracción del espacio

1fr

Fracción del espacio restante - distribuye equitativamente

Sin Media Queries

Se adapta automáticamente a todos los dispositivos
