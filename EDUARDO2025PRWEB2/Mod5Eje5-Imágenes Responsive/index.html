Imágenes Responsive - Guía Completa

Abre las herramientas de desarrollador (F12) y redimensiona la ventana para ver los cambios en tiempo real.

1. Srcset y Sizes (Misma imagen, distintos tamaños)

El navegador elige automáticamente la mejor imagen basándose en el ancho de pantalla y la densidad de píxeles (DPI).

Código utilizado:

srcset=" https://placehold.co/400x300/... 400w, https://placehold.co/800x600/... 800w, https://placehold.co/1200x900/... 1200w, https://placehold.co/1600x1200/... 1600w "

sizes="(max-width: 600px) 100vw, (max-width: 900px) 50vw, 33vw"

¿Cómo funciona?

El navegador calcula el tamaño necesario para la imagen según el sizes y luego elige la imagen más apropiada del srcset.

Ejemplo: En una pantalla de 1200px, el tamaño será 33% = 400px. El navegador elegirá la imagen de 400w para pantallas 1x, o 800w para pantallas 2x (Retina).

2. Elemento Picture (Art Direction)

Usamos imágenes diferentes según el tamaño de pantalla para optimizar la composición visual.

Mobile: <768px
Tablet: 768px-1024px
Desktop: >1024px

Art Direction

No se trata solo de cambiar el tamaño, sino de cambiar la composición de la imagen para adaptarse mejor a cada dispositivo.

Mobile: Imagen cuadrada o vertical, enfoque en el sujeto principal.

Desktop: Imagen panorámica, más detalles y contexto.

3. Background Image Responsive (CSS)

La imagen de fondo de este div cambia según media queries en CSS usando background-image.

Contenido sobre el fondo adaptativo

CSS utilizado:

background-image: url('imagen-mobile.jpg');

@media (min-width: 768px) { background-image: url('imagen-tablet.jpg'); }

@media (min-width: 1024px) { background-image: url('imagen-desktop.jpg'); }

Propiedades importantes: background-size: cover, background-position: center

4. Comparativa de Métodos

Cada técnica tiene sus ventajas y casos de uso específicos.

¿Cuándo usar cada método?

srcset + sizes: Para imágenes de contenido (fotos en artículos, galerías) donde solo cambia el tamaño.

Picture element: Cuando necesitas cambiar la composición o recorte de la imagen (art direction).

Background-image: Para imágenes decorativas, banners hero, o elementos de diseño.

img con max-width: 100%: La solución más simple para imágenes que deben escalar con su contenedor.
